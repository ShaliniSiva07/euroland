# euroland
A static corporate website inspired by Euroland IR, built using HTML5 and CSS3 to practice modern webpage layouts, CSS Grid, Flexbox, and UI design.

Euroland IR Website Clone

This project is a static corporate website inspired by the Euroland IR website. It was developed using HTML5 and CSS3 as part of my frontend learning journey. The project focuses on recreating a professional corporate webpage with structured layouts and clean styling.

Features :
Professional navigation bar
Hero section
About Us section
Services section with hover effects
Client testimonials
Client logo showcase
Statistics section with background image overlay
Global offices section using CSS Grid
Corporate-style footer with contact information
Font Awesome icons integration

Semantic HTML structure

Image positioning
Icons and UI components
Static webpage design

Project Purpose:

The purpose of this project was to strengthen my frontend development skills by recreating the layout and design of a real-world corporate website. Through this project, I gained practical experience in building structured web pages, working with CSS Grid and Flexbox, styling different website sections, and creating a clean, professional user interface.
